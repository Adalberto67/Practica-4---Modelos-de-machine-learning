# Práctica 4 · Redes neuronales (Streamlit)

Página interactiva con tres redes neuronales: clasificación (mantenimiento predictivo), regresión
(planta de ciclo combinado) y series de tiempo (sistema hidráulico). Cada red se entrena desde la
página, muestra sus resultados y puede probarse con valores elegidos por el usuario.

Archivos:
- `app.py` – interfaz (páginas, pestañas, formularios de prueba)
- `redes.py` – datos, entrenamiento y predicción de las tres redes
- `estilo.py` – diseño (CSS, tablas y tarjetas)
- `requirements.txt` – bibliotecas necesarias
- `.streamlit/config.toml` – colores del tema

Ejecutar en una computadora: `pip install -r requirements.txt` y luego `streamlit run app.py`.
